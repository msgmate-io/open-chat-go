Use the Python client package to log in and create an interaction chat.

### Local client usage

```bash
python3 -m venv venv
source venv/bin/activate
pip install -e ./clients/oc_python_client
```

### General client usage

```python
from client.client import OpenChatPythonClient

client = OpenChatPythonClient(
    host="http://localhost:1984",
    username="admin",
    password="password",
)

user = client.login()
print("Logged in:", user.name)

chat = client.create_interaction(message="Hello from Python")
print("Chat UUID:", chat.uuid)

# API token auth (no login call needed)
token_client = OpenChatPythonClient(
    host="http://localhost:1984",
    api_token="ocat_xxx",
)
print("Token user:", token_client.get_user_self().name)
```

CLI variant:

```bash
oc_client --host http://localhost:1984 --username admin --password password --message "Hello from CLI"
oc_client --host http://localhost:1984 --api-token ocat_xxx --message "Hello from CLI"
```

### Configuring the interaction


```python
client.setup_bot_config({
    "temperature": 0.7,
    "max_tokens": 4096,
    "model": "deepseek-ai/DeepSeek-V4-Flash",
    "endpoint": "https://api.deepinfra.com/v1/openai",
    "backend": "deepinfra",
    "context": 10,
    "system_prompt": "You are a helpful assistant.",
})
```
