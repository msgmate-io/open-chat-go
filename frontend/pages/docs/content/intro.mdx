Open Chat Go is a federated chat platform that combines a Go backend, a React
frontend, an async worker queue, and a growing set of LLM models, tools and
integrations.

This documentation covers the **public** surface of the platform: the REST and
WebSocket APIs, the chat and interaction model, bots and agents, models and
tools, the supported clients, and how to self-host the server. Internal
administration material is intentionally excluded.
