This page covers the local development workflow for Open Chat Go. For deployment
and the complete command reference, see [Self-hosting](/docs#self-hosting) and
[Server CLI](/docs#server-cli).

## Prerequisites

- Go (the version declared in `backend/go.mod`).
- Node.js 20+ for the frontend.
- Docker with Compose v2 (recommended for the bundled dev stack).

## Clone the repository

The core frontend is tracked in-tree under `frontend/`. Only the public
submodules are checked out with the clone (the Go interfaces, the Python/JS
clients and the build tools):

```bash
git clone --recurse-submodules https://github.com/msgmate-io/open-chat-go.git
# existing clone:
git submodule update --init --recursive
```

Integration source is not a submodule: it is fetched on demand from
`integrations.yaml` by the integration manager. See
[Integration Development](/docs#integration-development) for the manifest,
profiles and the manager CLI.

## Run the dev stack

```bash
docker compose build
# frontend + backend (sqlite + hot reload)
docker compose up
# or the design system
docker compose --profile storybook up
```

The server and embedded frontend are available at `http://localhost:1984`.
Frontend and backend code reloads automatically, so you can call endpoints
directly while you work. The stack runs an `integration-sync` service that
fetches the selected integrations and generates the Go workspace before the
backend starts.

Integrations are selected per profile via `INTEGRATION_PROFILE`; the public
default is `core-only`:

```bash
INTEGRATION_PROFILE=core-only docker compose up
```

## Repository layout

| Path | Contents |
| --- | --- |
| `frontend/` | React + Vike frontend, the `/docs` pages and the `@open-chat-go/ui` package. |
| `backend/` | Go server, API handlers, queue workers and database models. |
| `clients/` | Official clients and the public interfaces. |
| `integrations.yaml` | Integration manifest: sources, profiles and frontend pages. |
| `development/` | Build, packaging and release helper scripts. |

## Tests and checks

- Backend: `go build ./...` then `go test ./...`.
- Frontend: `npm install && npm run build` inside `frontend/`.
- Call the affected endpoints against `http://localhost:1984` and confirm the
  responses while implementing.
